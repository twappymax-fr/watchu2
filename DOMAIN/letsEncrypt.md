# HTTPS Setup for a Dockerized Django Application Using Let's Encrypt

## Recommended Architecture

This guide assumes:

- Django runs in a Docker container
- Gunicorn serves Django
- Nginx runs in a Docker container
- PostgreSQL runs in a Docker container
- Ubuntu VPS
- Custom domain purchased and configured

Recommended approach:

- Install Certbot directly on the VPS host
- Generate certificates on the host machine
- Mount certificates into the Nginx container

This approach is simpler, more reliable, and easier to troubleshoot than running Certbot inside Docker.

---

```text
Internet
    |

    v
VPS
 ├── Certbot (Host Machine)
 └── Docker

      └── PostgreSQL
```

# Step 1: Point Your Domain to Your VPS

At your domain registrar, create:

| Type | Host | Value |
|--------|--------|--------|
| A | @ | VPS_IP |
| A | www | VPS_IP |

Example:

```text
A      @      123.123.123.123
A      www    123.123.123.123
```

Wait for DNS propagation.

Verify:

```bash
nslookup example.com
```

or

```bash
dig example.com
```

Expected:

```text
example.com -> VPS_IP
```

---

# Step 2: Configure Django

Update your `.env.prod`:

```env
DEBUG=False

ALLOWED_HOSTS=example.com,www.example.com

CSRF_TRUSTED_ORIGINS=https://example.com,https://www.example.com
```

In `settings.py`:

```python
ALLOWED_HOSTS = os.getenv(
    "ALLOWED_HOSTS",
    ""
).split(",")

CSRF_TRUSTED_ORIGINS = os.getenv(
    "CSRF_TRUSTED_ORIGINS",
    ""
).split(",")
```

---

# Step 3: Open Firewall Ports

Ubuntu:

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

sudo ufw reload
```

Verify:

```bash
sudo ufw status
```

---

# Step 4: Deploy Docker Containers

Build:

```bash
docker compose build
```

Start:

```bash
docker compose up -d
```

Verify:

```bash
docker ps
```

---

# Step 5: Configure Nginx for HTTP

Example:

```nginx
server {

    listen 80;

    server_name example.com www.example.com;

    location / {

        proxy_pass http://web:8000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /static/ {
        alias /app/staticfiles/;
    }

    location /media/ {
        alias /app/media/;
    }
}
```

Replace:

```text
example.com
```

with your real domain.

Restart:

```bash
docker compose restart nginx
```

---

# Step 6: Verify HTTP Works

Visit:

```text
http://example.com
```

and

```text
http://www.example.com
```

Do not continue until both work.

---

# Step 7: Install Certbot on the VPS

SSH into the VPS:

```bash
sudo apt update

sudo apt install certbot -y
```

Verify:

```bash
certbot --version
```

---

# Step 8: Stop Nginx Temporarily

Port 80 must be available.

```bash
docker stop nginx
```

Replace `nginx` with your container name if different.

---

# Step 9: Generate SSL Certificates

Run:

```bash
sudo certbot certonly --standalone \
-d example.com \
-d www.example.com
```

Successful certificates will be stored at:

```text
/etc/letsencrypt/live/example.com/
```

Files:

```text
fullchain.pem
privkey.pem
```

---

# Step 10: Mount Certificates into Nginx

Update your `docker-compose.yml`:

```yaml
services:

  nginx:

    image: nginx:latest
    ports:
      - 80:80
      - 443:443
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - /etc/letsencrypt:/etc/letsencrypt:ro
```

This allows Nginx to access the certificates generated by Certbot.

---

# Step 11: Configure HTTPS

Update Nginx:

```nginx
server {

    listen 443 ssl;

    server_name example.com www.example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    location / {

        proxy_pass http://web:8000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /static/ {
        alias /app/staticfiles/;
    }

    location /media/ {
        alias /app/media/;
    }
}
```

---

# Step 12: Redirect HTTP to HTTPS

Add a second server block:

```nginx
server {

    listen 80;

    server_name example.com www.example.com;

    return 301 https://$host$request_uri;
}
```

---

# Step 13: Configure Django for HTTPS

Add to `settings.py`:

```python
SECURE_PROXY_SSL_HEADER = (
    "HTTP_X_FORWARDED_PROTO",
    "https",
)
```

Recommended production settings:

```python
SECURE_SSL_REDIRECT = True

SESSION_COOKIE_SECURE = True

CSRF_COOKIE_SECURE = True
```

---

# Step 14: Restart Containers

Start Nginx again:

```bash
docker start nginx
```

Or:

```bash
docker compose restart nginx
```

Verify:

```bash
docker ps
```

# Step 15: Test HTTPS

Visit:

```text
https://example.com
```

You should see:

- Secure padlock
- No certificate warnings
- Working CSS and JavaScript
- Successful login and forms

---

# Step 16: Test Renewal

Let's Encrypt certificates expire every 90 days.

Test renewal:

```bash
sudo certbot renew --dry-run
```

Expected output:

```text
Congratulations, all simulated renewals succeeded.
```

---

# Step 17: Automatically Reload Nginx After Renewal

Create a deploy hook:

```bash
sudo certbot renew \
--deploy-hook "docker restart nginx"
```

This ensures Nginx begins using the renewed certificates immediately.
